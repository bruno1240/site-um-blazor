# SiteUmBlazor

Lista de exercícios de Blazor — Desenvolvimento Web (Prof. Daniel Henrique Matos de Paiva).

## Páginas

| Exercício | Rota        | Arquivo                            | Foco                          |
|-----------|-------------|------------------------------------|-------------------------------|
| 1         | `/sobre`    | `Components/Pages/Sobre.razor`     | `@page` (roteamento)          |
| 2         | `/contador` | `Components/Pages/Contador.razor`  | `@code` e `@onclick`          |
| 3         | `/mensagem` | `Components/Pages/Mensagem.razor`  | Estado booleano e `@if`       |
| 4         | `/placar`   | `Components/Pages/Placar.razor`    | Múltiplos eventos, regra ≥ 0  |

## Requisitos

- .NET SDK 10.0

## Como rodar

```bash
dotnet watch
```

Acesse `http://localhost:5080/sobre` (ou a porta exibida no terminal).
